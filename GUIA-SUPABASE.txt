GESTIONAR PRODUCTOS CON SUPABASE (imagen, nombre y descripción)
================================================================

QUÉ INCLUYE
- admin.html     Panel privado para cargar, editar, ocultar, ordenar y borrar productos
                 (usa css/admin.css y js/admin.js).
- supabase.sql   Crea la tabla, la carpeta de fotos y las reglas de seguridad.
- config.js      Dos datos de tu proyecto de Supabase (URL y clave pública).
- index.html     La página: si config.js está completo, muestra los productos cargados en el panel
                 (esa lectura está en js/supabase.js).

PASO A PASO (unos 15 minutos)
1) Entrá a supabase.com, creá una cuenta y un proyecto nuevo (anotá la contraseña de la base de datos).
2) Abrí supabase.sql con un editor de texto. Buscá CAMBIAR@CORREO.COM y poné el correo del administrador
   (en minúsculas). Guardalo.
3) En Supabase: SQL Editor > New query > pegá TODO el contenido de supabase.sql > Run.
   Debe decir "Success".
4) En Authentication > Users > Add user > Create new user: poné el MISMO correo del paso 2, una contraseña,
   y marcá "Auto Confirm User".
5) En Authentication > Sign In / Providers (o "Settings"): desactivá "Allow new users to sign up",
   para que nadie más pueda crear cuentas.
6) En Project Settings > API (o "API Keys") copiá:
   - Project URL                -> en config.js, SUPA_URL
   - clave pública (anon / publishable) -> en config.js, SUPA_KEY
   NUNCA uses la clave "service_role" ni "secret".
7) Subí TODA la carpeta (index.html, admin.html, config.js, css, js, imagenes...) a tu hosting.
8) Entrá a tudominio.com/admin.html, iniciá sesión y listo.

PRIMER USO
- Botón "Importar fotos actuales": sube al panel las fotos que ya están en la carpeta "imagenes"
  (las de cada categoría), con nombres como "Bibliotecas 03" para que luego los edites.
  Funciona solo si el sitio está en un hosting (no abriendo el archivo con doble clic).
- "+ Agregar producto": elegí categoría, escribí nombre y descripción y subí la foto
  (se reduce sola a un tamaño liviano). Podés marcarlo como "Destacado" para que salga en el carrusel.
- Filtro por categoría: arriba de la lista hay botones con cada categoría y la cantidad de productos. Tocá uno para ver
  solo esa; "Todas" muestra todo. El filtro se recuerda, y "+ Agregar producto" parte de la categoría elegida.
- Para cambiar el orden: agarrá el ícono ⋮⋮ de la izquierda de un producto, arrastralo y soltalo en su nuevo lugar
  (funciona con mouse y con el dedo). También están las flechas ↑ ↓ para moverlo de a uno.
- Cada producto tiene además botones para Editar, Ocultar y Eliminar.
- Arriba de la lista hay botones para FILTRAR por categoría (con la cantidad de fotos de cada una). El panel recuerda
  la última categoría elegida; "Todas" vuelve a mostrar todo.

CÓMO SE COMPORTA LA PÁGINA
- Si una categoría tiene productos en el panel, la página muestra esos. Si no tiene, sigue usando las fotos
  de la carpeta "imagenes".
- Si hay productos marcados como destacados, el carrusel usa esos.
- Las portadas de las categorías (las 9 fotos grandes) siguen siendo las de imagenes/portadas.
- Al hacer clic en una foto se abre la ficha con nombre, descripción y el botón de WhatsApp.
- Si Supabase no responde, la página sigue funcionando con las fotos de la carpeta.

SEGURIDAD
- La clave pública puede estar en la página: solo permite LEER productos visibles.
- Escribir, subir o borrar solo lo puede hacer el correo configurado en supabase.sql, con su contraseña.
- admin.html no está enlazado desde la página y pide contraseña, pero conviene no compartir su dirección.

CAMBIAR EL NOMBRE DE UNA CATEGORÍA (ejemplo: espejos -> armeros)
- En el sitio: js/datos.js (en C, FOTOS y DESTACADOS), js/admin.js (CATS y LOCALES), y renombrar las carpetas
  imagenes/espejos -> imagenes/armeros e imagenes/portadas/espejos.jpg -> armeros.jpg.
- En Supabase: ejecutar supabase-renombrar-categoria.sql (SQL Editor > Run) ANTES de subir el sitio actualizado.
  Ese archivo mueve los productos de la categoría vieja a la nueva. Para otra categoría, editá los nombres en el archivo.
- Si empezás un proyecto nuevo, supabase.sql ya trae la lista actualizada.
